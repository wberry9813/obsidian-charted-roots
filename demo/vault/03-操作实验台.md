# 操作实验台（历史研究主线）

## A. 时间线四层对照
1. 保持 Workspace = **三国·赤壁专题 · 历史研究**。
2. Open temporal timeline。
3. 搜索 `赤壁`。
4. 比较 Period / Process / Event / Assertion 的形态。
5. Group by Person / Place / Organization / Office。

## B. 曹操的制度状态
打开 [[示例/三国赤壁/People/曹操|曹操]] → Entity Profile。
把时间焦点放在 208 CE，检查丞相、汉朝廷 affiliation 与关系状态是否同时出现。

## C. 孙刘关系变化
Relationships 中观察 [[示例/三国赤壁/Assertions/刘备与孙权同盟|刘备与孙权同盟]]。
再把焦点移出有效区间，确认历史关系不会被当成永久关系。

## D. 208 → 209 历史地图切换
1. Open map view；
2. 聚焦 208 CE；
3. 看 [[示例/三国赤壁/Layers/208年秋荆州控制示意|208 控制层]]；
4. 聚焦 209 CE；
5. 看 [[示例/三国赤壁/Layers/209年荆州重组示意|209 控制层]]；
6. 检查 control layer 不确定性样式。

## E. possible control
打开 [[示例/三国赤壁/Assertions/刘备集团可能控制江陵|刘备集团可能控制江陵]]。
它只有 not-before / not-after，应进入 possible state，不应变成一个伪造的 definite 区间。

## F. 历史名称
打开 [[示例/三国赤壁/Places/许昌|许昌]] 与 [[示例/三国赤壁/Assertions/许昌历史名称许县|许昌历史名称许县]]。

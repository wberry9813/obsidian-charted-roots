关键空间链：
[[Places/襄阳|襄阳]] → [[Places/当阳长坂|当阳长坂]] → [[Places/江陵|江陵]] / [[Places/夏口|夏口]] → [[Places/樊口|樊口]] → [[Places/柴桑|柴桑]] → [[Places/赤壁战场候选区|赤壁战场候选区]] / [[Places/乌林|乌林]] → [[Places/江陵|江陵]]。

Place 只保存稳定的现代 WGS84 研究锚点；历史名称、政权控制、行政归属与战场范围全部另做时间化数据。

这样切换历史时间时，**同一个地点实体**可以显示不同历史名称、不同控制状态，而不是复制成多个互不相干的 Place。

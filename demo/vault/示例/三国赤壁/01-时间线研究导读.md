# 时间线研究导读

历史 Timeline 的重点不是把所有东西排成一列，而是**区分不同性质的时间对象**。

| 类型 | 本专题示例 | 研究意义 |
|---|---|---|
| Period | 建安十三年南征与赤壁阶段 | 研究者人为划定的背景区间 |
| Process | 曹操南征荆州、孙刘联盟形成与维系 | 持续变化，没有唯一发生瞬间 |
| Event | 长坂之战、赤壁交战、黄盖火攻 | 相对集中的历史节点 |
| Assertion | 曹操任丞相、孙刘同盟、控制江陵 | 某一段时间内成立的状态 |

## 建议操作

1. 打开 Temporal Timeline；
2. 搜索 `赤壁`；
3. 搜索 `曹操`；
4. 分别 Group by Person / Place / Organization / Office；
5. 在 208 CE 附近点击时间轴；
6. 再打开 Relationships / Profile / Map，观察 Shared Temporal Focus。

### 要特别看的一点
`208 CE` 是 **year precision**。插件应把它理解为整年区间，而不是偷偷变成 208-01-01。

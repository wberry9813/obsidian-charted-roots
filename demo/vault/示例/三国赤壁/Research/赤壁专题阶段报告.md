# 赤壁专题阶段研究报告

## 1. 研究范围
本阶段聚焦 208–210 CE，核心不是重述“火烧赤壁”的故事，而是观察**荆州政治控制、孙刘合作、曹操南征与战后空间重组之间的关系**。

## 2. 当前时间重建
### 208 CE
- 曹操复置丞相并自任；
- 刘表去世；
- 刘琮降曹；
- 刘备集团在长坂遭追击并继续南撤；
- 鲁肃与刘备接触；
- 诸葛亮赴柴桑；
- 孙权内部形成拒曹决策；
- 孙刘军在赤壁方向与曹军交战，随后发生火攻与曹军退却；
- 战事继续向江陵/南郡延伸。

### 209–210 CE
- 江陵/南郡控制继续变化；
- 刘备集团向荆南扩展；
- “赤壁胜利”因此不应被视为一切政治空间变化的终点。

## 3. 人物与制度状态
曹操在本专题中被同时建模为：
- Person；
- 汉丞相 Office holder；
- 汉朝廷 affiliation；
- 曹操集团政治核心；
- 刘备/孙权的敌对者。

这些状态互不覆盖，使 Profile 能回答“某一时点的曹操是谁”，而不是只展示一张静态人物卡。

## 4. 孙刘联盟
当前 Assertion 把 208–219 CE 作为研究窗口，但：
- 起点标记 approximate；
- 终点标记 disputed；
- Research Log 明确记录终点仍需后续专题材料。

因此系统可以使用这条关系进行时间化查询，同时不把分析边界伪装成确定史实。

## 5. 荆州控制
控制权被拆成多个独立 Assertion：
- 刘表集团控制襄阳/江陵；
- 曹操集团控制襄阳/江陵；
- 孙权集团控制江陵；
- 刘备集团对江陵只设置 constraint window，进入 possible state。

这比一个 `owner: X` 字段更适合历史研究，因为政权控制会随时间变化，而且来源可信度并不相同。

## 6. 赤壁地望
Map 中的“赤壁战场候选区”只是一枚检索锚点。
《水经注》的历史地理线索与宋人“江夏辨疑”都说明地望需要证据链讨论；因此 [[示例/三国赤壁/Claims/赤壁战场位置应保持争议状态|地望 Claim]] 保持 disputed。

## 7. 证据结构
本阶段已建立：
- 三国志不同纪传 → Source；
- 资治通鉴卷六十五 → Source；
- 水经注 / 宋人地理考辨 → Source；
- 每条具体支持关系 → Citation；
- 可检验历史状态 → Assertion；
- 战役链、联盟性质、鲁肃作用、地望等解释 → Claim。

## 8. 当前不能解决的问题
1. `建安十三年` 尚不能由 chronology provider 原生解析；
2. 赤壁战场无法仅凭当前资料压缩到精确坐标；
3. 孙刘联盟结束点仍需扩展到 215–219 CE 的荆州争夺材料；
4. Historical Control Layer 目前是研究示意，不是专业历史 GIS 边界；
5. 还没有接入真正的中国历史地形/古城瓦片底图。

## 9. 插件在本专题中真正提供的帮助
- 不把不同时间尺度压成 Event 列表；
- 不把官职、阵营和关系写死在人物上；
- 不让后来的政治实体倒灌到更早时间；
- 能把地图控制权与 Timeline 共享时间焦点；
- 能区分 Source / Citation / Assertion / Claim；
- 能保存 negative / inconclusive 研究日志；
- 对不支持的纪年保持 unresolved，而不是猜。

## 10. 下一研究阶段
如果继续把这个专题做成真实研究库，下一步应扩展：
- 215 CE 湘水划界；
- 219 CE 荆州易手；
- 江陵/公安/南郡的更细地点层级；
- 《三国志》裴松之注中不同来源的 source hierarchy；
- 历史 DEM / 古河道 / 古城址底图与 GIS 控制层。

# 左传

历史研究 Workspace 的 Source 示例。

## 证据链示例

[[示例/春秋战国/Sources/左传|Source]] → [[示例/春秋战国/Citations/左传支持管仲任相|Citation]] → [[示例/春秋战国/Assertions/管仲任齐相|Assertion]] → [[示例/春秋战国/Claims/齐国霸业结构|Claim]]。

这四层的职责不同：

- **Source**：史料/资料实体；
- **Citation**：指出该来源的哪个位置、以什么关系支持/反对某一目标；
- **Assertion**：可检验的事实陈述；
- **Claim**：研究者在多个事实基础上形成的解释或判断。

## 演示重点

不要把“引用了《左传》”直接等同于“某个历史解释已经成立”。Charted Roots v2 用实体分层让来源、事实和作者判断保持可追踪。

> Demo Citation 的 locator 是占位信息，不应作为真实引文定位。

# 春秋时期

**Period** 用于提供历史研究中的大尺度背景区间。它不是一个发生了什么的 Event，也不是研究者提出的 Claim。

## Demo 中的时间层级

1. Period：春秋时期；
2. Process：[[示例/春秋战国/Processes/春秋争霸|春秋争霸]]；
3. Event：[[示例/春秋战国/Events/葵丘会盟|葵丘会盟]] / [[示例/春秋战国/Events/管仲拜相|管仲拜相]]；
4. Assertion：[[示例/春秋战国/Assertions/管仲任齐相|管仲任齐相]]。

在 Temporal Timeline 中同时显示四类对象，是历史 Workspace 与普通家谱 Timeline 最重要的区别之一。

> 起止年采用本 Demo 的统一时间轴口径，用于软件能力展示。

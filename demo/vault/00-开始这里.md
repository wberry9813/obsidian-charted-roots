# Charted Roots 满血 Showcase

这个 Vault 的目标不是“给几篇示例文档”，而是让你把 Charted Roots 的主要能力真正**点一遍、看一遍、操作一遍**。

> [!important]
> 历史、家谱和世界观内容主要服务于软件演示。标注为 Demo / 示意的数据、坐标、边界、研究结论都不能作为真实史学或家谱证据使用。

## 三套完整 Workspace

| Workspace | 用来展示什么 |
|---|---|
| **林氏家族 · 家谱研究** | Family Chart、Canvas、Calendar、Profile、Relationships、媒体、来源、研究、DNA、统计、报告、Book、导入导出、Data Quality |
| **春秋战国 · 历史研究** | BCE、Event / Process / Period、动态关系、组织/官职、Assertion、Source/Citation/Claim、历史 Map |
| **蜀山 · 世界观** | Universe、自定义历法、fictional Timeline、组织、Custom Image Map、linked map、Transfers |

## 建议第一轮：10 分钟看“满血”效果

### 1. Family Chart

切到 **林氏家族 · 家谱研究**，命令面板执行：

**Charted Roots: Open Family Chart**

根人物选 **林晨**。

你应该能看到：

- 祖父母与外祖父母；
- 父母与兄弟姐妹；
- 两段婚姻；
- biological child；
- step-child；
- adoptive branch；
- 非亲属 mentor / DNA match 不被错误当成血缘树。

再试：

- Highlight groups
- Custom Relationships overlay
- 新开第二个 Family Chart
- Canvas tree generation
- Re-layout
- PNG / SVG / PDF / ODT export

### 2. 一篇人物笔记看动态块

打开 [[示例/林氏家族/People/林晨|林晨]]，切到阅读视图。

这页已经预置：

- Timeline
- Relationships
- Media Gallery
- Sources
- Negative Findings

同时 frontmatter 里还有：

- 多婚姻元数据
- step-child
- mentor
- DNA match
- 事实级来源
- 4 段人生地理事件

### 3. Profile / Relationships / Calendar / Map

依次运行：

- **Open entity profile**
- **Open relationships**
- **Open calendar view**
- **Open map view**

林晨的数据刻意覆盖了精确日期、迁居、教育、婚姻、地点层级，所以这些 View 不会是空白。

### 4. Statistics 与 Data Quality

运行：

- **Open statistics dashboard**
- **Open data quality**

Demo 中故意准备了：

- 高/低 research level
- living / deceased
- 多婚姻
- DNA match
- 有来源 / 无来源
- 未连接人物
- 疑似重复人物
- private 字段
- 缺失父母
- 收养 / 继亲

这样统计和质量分析能看到真实分布。

### 5. Reports

运行 **Open report wizard**，优先试：

- Family Group Sheet
- Individual Summary
- Kinship Report
- Ahnentafel
- Gaps Report
- Brick Wall Report
- Unconnected People
- Source Summary
- Sources by Role
- Media Inventory
- Place Summary

### 6. Book Builder

右键 [[示例/林氏家族/Books/林氏家族小史.book.json|林氏家族小史.book.json]]。

它已经配置好：

- 封面
- Vault Note 章节
- 林晨 Individual Summary
- Pedigree visual tree
- Research Report
- TOC
- Bibliography
- Name Index

### 7. Historical v2

切换到 **春秋战国 · 历史研究**：

- Temporal Timeline 同时看 Event / Process / Period / temporal Assertion；
- Profile 看 affiliation + office_holding；
- Relationships 看时变关系；
- Map 看 BCE focus + historical control layer；
- Sources / Citations / Claims 看“史料 → 事实断言 → 作者判断”的分层。

### 8. Worldbuilding

切换到 **蜀山 · 世界观**：

- 打开 [[示例/蜀山/Universes/蜀山世界|蜀山世界]]；
- Timeline 看自定义 **蜀山纪年**；
- Map 选择 **蜀山全图**；
- 点击峨眉标记 drill down 到 **峨眉山区域**；
- 打开 [[示例/蜀山/People/李英琼|李英琼]] 看 affiliation / relationships / transfers。

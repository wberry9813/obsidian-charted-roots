# Charted Roots 满血历史研究 Showcase

这次 Demo 的重点已经明确调整为：**历史研究优先**。

默认 Workspace：**三国·赤壁专题 · 历史研究**。

## 第一入口

打开：[[示例/三国赤壁/00-研究总览|三国·赤壁专题研究台]]

专题研究的问题不是“曹操是谁”，而是：
- 208 CE 荆州权力结构如何快速重组？
- 孙刘联盟如何形成、维系并最终裂解？
- 赤壁是一个战斗点，还是一条连续战役链？
- 同一人物的官职、阵营和关系如何随时间改变？
- 一个史料如何通过 Citation 支持某条 Assertion，再被研究者用于 Claim？
- 历史地名、控制权、边界和战场地望如何随时间变化并保留不确定性？

## 10 分钟历史满血路线

1. 打开 **Temporal Timeline**：看 Period / Process / Event / Assertion 同轴。
2. 搜索 `曹操`，Group by **Person**。
3. Group by **Organization**，看汉朝廷、曹操集团、刘备集团、孙权江东政权。
4. 打开 [[示例/三国赤壁/People/曹操|曹操]] 的 Entity Profile，看丞相与 affiliation。
5. 打开 Relationships，看孙刘同盟、曹刘/曹孙敌对的时间区间。
6. 打开 Map，先聚焦 208 CE，再切 209 CE，看 Historical Control Layer 替换。
7. 打开 [[示例/三国赤壁/05-证据链怎么读|证据链怎么读]]。
8. 顺着 [[示例/三国赤壁/Sources/三国志·周瑜鲁肃吕蒙传|Source]] → Citation → [[示例/三国赤壁/Assertions/刘备与孙权同盟|Assertion]] → [[示例/三国赤壁/Claims/孙刘联盟是条件性合作而非永久共同体|Claim]] 追一遍。
9. 打开 [[示例/三国赤壁/Research/赤壁专题研究|Research Project]] 与 Research Timeline。
10. 最后看 [[示例/三国赤壁/Research/赤壁专题阶段报告|阶段报告]] 和 Book Builder。

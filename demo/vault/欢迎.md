# Charted Roots v2 中文 Demo Vault

这个 Vault 是为 **Multi-Workspace / 历史研究 / 世界观 / 时间线 / 地图 / 史料证据链** 人工验收准备的开箱样例。

> [!important]
> 示例中的历史关系、时间和地图边界主要用于验证软件结构与交互。它们不是完整史学结论；其中标明“演示”的坐标或边界尤其不应作为研究数据引用。

## 已预置

- **春秋战国 · 历史研究**
  - 齐桓公、管仲
  - 齐国 / 齐国朝廷 / 齐相
  - 管仲拜相、葵丘会盟
  - 春秋争霸（Process）与春秋时期（Period）
  - affiliation / office_holding / relationship Assertions
  - 《左传》Source、Citation、Claim
  - 临淄、葵丘地点与一层示意 GeoJSON

- **蜀山 · 世界观**
  - 李英琼、余英男
  - 峨眉派
  - 紫郢剑出世、正邪斗剑
  - 自定义 **蜀山纪年**：旧纪 `BY` / 蜀历 `SY`
  - fictional chronology Timeline / Map 测试数据

## 推荐查看顺序

1. 打开 **设置 → Charted Roots**，确认界面默认是中文。
2. 命令面板搜索 **Charted Roots**，打开 **管理工作区**。
3. 在两个 Workspace 之间切换，观察人物、事件、时间线和地图是否完全隔离。
4. 打开 Temporal Timeline，在历史 Workspace 看 BCE，在蜀山 Workspace 看 `SY` 纪年。
5. 打开地图，检查地点、共享时间焦点和示意控制层。
6. 查看 `Assertions/`、`Sources/`、`Citations/`、`Claims/`，体验事实与证据分层。

普通插件 artifact 不会包含这些测试数据；只有 Demo Vault artifact 才包含。
